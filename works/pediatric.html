Pediatric Clinic — Website Renewal

初めての受診でも、迷わない。保護者が「今すぐ知りたいこと」へ最短で辿り着けるよう、実際の行動を観察しながら導線を組み直しました。診療時間・アクセス・受診の流れを軸に、不安を和らげる情報設計を心がけています。

CategoryWeb Design
Year2025
RoleDesign, Coding
ToolsFigma, HTML · CSS
01課題 / The Challenge

情報は揃っているのに、必要なものが探しにくい——。急いでいる保護者ほど迷ってしまう構造が課題でした。ページ間の関係も曖昧で、初めての人が全体像を掴みづらい状態でした。

02アプローチ / The Approach

よく参照される「診療時間」「アクセス」「受診の流れ」を上位に再配置。休診が一目で分かる時間表と、不安を先回りで解消する「はじめての方へ」を新設し、初診でも迷わない縦の導線に整理しました。
