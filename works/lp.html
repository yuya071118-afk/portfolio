Landing Page Design

訴求を、一直線に。ファーストビューから行動まで、視線が迷わない縦の流れを設計しました。要素を絞り、コンバージョンにつながる構成と訴求順序にこだわっています。

CategoryLanding Page
Year2025
RoleDesign, Coding
ToolsFigma, HTML · CSS
01課題 / The Challenge

情報量が多く、ユーザーが「何をすればいいか」を見失いやすい構成でした。離脱ポイントも曖昧なままでした。

02アプローチ / The Approach

訴求→根拠→安心→行動の順に再設計。CTAを要所に配置し、装飾より読みやすさを優先。1本の線を辿るように読み進められる流れに整えました。
